# 請求書消込ツール（ヤシマ様）

電材商社から受け取る**請求書の明細**と、**メタフォースの仕入データ**を突き合わせ、

- 請求書の消込（どの請求行がどの仕入行に当たるか）
- 単価・数量の誤りチェック
- 請求漏れ・仕入未計上の洗い出し

をまとめて行うブラウザ用ツールです。インストール不要で、データはパソコンの外に送信されません。

## 対応している仕入先の形式

列は見出し名で探すので、下記以外の仕入先でも見出しが近ければそのまま読めます。

| 仕入先 | 請求書の形式 | 主な列 |
|---|---|---|
| ヤシマ電材 | Excel（請求明細シート） | 月日・伝票番号・商品名・内容・数量・単価・金額・備考 |
| 山善 | CSV（Shift-JIS） | 出荷日・請求伝票番号・メーカー・商品名・形式・数量・税抜き単価・税抜き金額・得意先注番 |
| コイズミ照明 | Excel（統合明細データ） | 注番・品番・数量・単価・金額（日付・伝票番号・品名なし） |

仕入データはメタフォースの「仕入伝票明細表」CSV（Shift-JIS）と、列を絞った Excel のどちらも読めます。
山善 CSV の伝票見出し行（数量・金額のない行）は自動で除きます。

仕入先ごとのよくあるパターンも自動で処理します。
- **値引き・単価訂正の行**（コイズミ）：請求 2個×31,920円 ＋ 値引 −2個×1,680円 ＝ 仕入 2個×30,240円 → ○
- **セット品の単価の振り分け違い**（山善）：同じ発注番号の中で合計が一致すれば → ○
- **0円明細**（セット部材・無償品）：支払いに影響しないので → ◎
- **送料・運賃**：一般的な語なので、発注番号か伝票番号が合うときだけ対応させる

## 使い方

1. `dist/請求書照合ツール.html` をダブルクリックしてブラウザ（Chrome / Edge）で開く
2. ① に請求明細の Excel、② にメタフォースの仕入データ Excel をドロップ
   （仕入データは前月・翌月分が混ざっていて構いません。期ズレ・繰越は気にしなくてOK）
3. 「照合する」を押す
4. 請求書の明細 1 行ごとに ◎○△× と一致率（％）が付くので、手間のかかる行だけ確認する
5. 「結果をExcelで保存」で、集計・消込結果・参考（使われなかった仕入）を保存

作業内容（消込チェック・メモ・手動の付け替え）はブラウザに自動保存され、同じ請求書ファイルを読み込むと続きから再開できます。

※ Excel の読み込みに SheetJS を CDN（cdnjs）から読み込むため、ネット接続が必要です。

## ◎○△× の意味

あくまで **請求書の明細 1 行ずつが消し込めるか** を判定します（請求書と仕入データの合計は期ズレがあるので比べません）。

| マーク | 意味 | やること |
|---|---|---|
| ◎ 確認不要 | 品番がほぼそのまま見つかり、数量・単価・金額も一致（取消の相殺・調整行も含む） | 何もしない（自動で消込済み） |
| ○ さっと目視 | 数量・単価・金額は一致。品番の書き方が違う／単位が違う（巻⇔m）／0円明細 | 品名を見て「○をまとめて消込」 |
| △ 要確認 | 相手は見つかったが単価・数量が違う／有力な候補がある（別の請求行で使用済み＝二重請求の疑いも表示） | 差異を確認、または候補から「これで消込」 |
| × 手で探す | 一致率 50% 以上の候補がない | 仕入未計上・二重請求を確認 |

### 仕入データから見る（逆方向）

画面上部の「仕入データから見る」に切り替えると、仕入 1 行ずつに、この請求書で請求されているかを判定します。請求漏れや翌月請求の確認に使います。

| マーク | 意味 |
|---|---|
| ◎ 確認不要 | 請求あり（一致）、仕入データ内の赤黒相殺、0円の仕入 |
| ○ さっと目視 | 請求あり（品番の表記違いなど）、または請求明細の最終日より後の仕入（翌月請求の見込み） |
| △ 要確認 | 請求に単価・数量の差異がある、または請求明細の最初の日より前の仕入（前月に請求済みか確認） |
| × 請求なし | 請求期間内なのに請求がない（請求漏れの可能性） |

請求のない仕入行には、近い請求明細を候補として表示します（別の仕入行と消込済みのものも含む）。「これで消込」で付け替えられます。請求書に日付がない形式（コイズミ）は期間を判定できないため、請求のない仕入はすべて × になります。

**一致率（％）** ＝ 品番・品名の一致度 50％ ＋ 発注番号／伝票番号 15％ ＋ 数量・単価・金額 35％（期ズレがあるので日付は含めない）

△ と × の行には、一致率の高い仕入行の候補（最大 3 件）が並び、ボタン 1 つで消込できます。
すでに別の請求行で使われている仕入行を選ぶと、付け替えるか確認します。

## 照合の仕組み

請求行 × 仕入行のすべての組合せを点数化し、点の高い順に 1 対 1 で確定します。

- **品番**：全角/半角、記号、大文字小文字をそろえ、OCR の読み違い（I⇔1、O⇔0、バ⇔パ、小書きカナ）を吸収した上で、請求の商品名の中に仕入の品番がどれだけ含まれるかを見る
- **品名**、**発注番号**（請求の備考 ⇔ 仕入の発注№）、**伝票番号**、**日付の近さ**、**数量・単価・金額の一致**
- 品番の表記がまったく違っても、伝票番号か発注番号が合い、金額と数量/単価が一致すれば同じ明細とみなす
- 1 行ずつ分けて計上された明細（例：1個＋9個 ⇔ 10個）はまとめて照合
- 「送料／運賃／ソウリョウ」などの同義語はそろえて比較

列は見出し名で探すので、列の並びが変わっても動きます（`src/readers.js` の見出し候補を参照）。

## ファイル構成

```
index.html          画面（開発用。src/*.js を読み込む）
src/matcher.js      照合ロジック
src/readers.js      Excel → 照合用データ への変換
tools/build.js      配布用の 1 ファイル版を dist/ に作る
dist/請求書照合ツール.html  配布用（これだけ渡せば使える）
```

`src/` や `index.html` を変更したら `node tools/build.js` で dist を作り直してください。
